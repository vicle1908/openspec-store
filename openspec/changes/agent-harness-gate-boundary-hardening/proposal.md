# agent-harness-gate-boundary-hardening

## Why

The ecosystem review identified three security/correctness gaps in agent-harness:

1. **Symlink validation bypass in `validate_artifact_root()`**: The function calls `.expanduser().resolve()` BEFORE scanning path components for symlinks. On macOS, `/var` is a symlink to `/private/var`; `resolve()` canonicalizes it away, making the subsequent component scan unable to detect the original symlink. A crafted artifact root containing a symlink component will pass validation. This is a TOCTOU-class issue.

2. **Authorization boundary lacks regression tests**: `ConfigFileResolver` is intentionally fail-closed (always returns `UNAVAILABLE_PROVIDER`). `unavailable_gate_resolver()` returns a `ConfigFileResolver` instance. The harness `_resume_compiled()` defaults to this when no resolver is provided. The behavior is correct but has no explicit test proving unauthorized callers cannot bypass the gate.

3. **Generated graphify artifacts tracked as source**: `.graphify_labels.json` and `.graphify_labels.json.sig` are generated by graphify, have zero Python consumers in the harness codebase, and are deleted in the current worktree diff. They should be gitignored.

## What Changes

### Security
- Fix `validate_artifact_root()` in `workspace.py` to scan user-supplied path components for symlinks BEFORE calling `resolve()`.
- Document the TOCTOU caveat: the check is best-effort; symlink creation between check and use is not prevented.
- Define strict symlink rejection: reject ALL symlink components including platform aliases like `/var` on macOS. Callers must use canonical paths (e.g. `/private/var`). The removed macOS platform symlink test confirms this is intentional.

### Authorization
- Add regression tests proving `unavailable_gate_resolver()` rejects authorization even when `TDT_ACTOR_ID` is present.
- Add test proving separation of duties is enforced.

### Cleanup
- Remove `.graphify_labels.json` and `.graphify_labels.json.sig` from git tracking.
- Add them to `.gitignore`.
- Document the regeneration path.

### Repos in scope
- `agent-harness` (workspace.py, tools/graphify.py, tests/test_config.py, tests/test_lifecycle_auth.py)
