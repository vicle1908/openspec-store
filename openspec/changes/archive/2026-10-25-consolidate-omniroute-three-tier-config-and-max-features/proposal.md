# Proposal

## Why

OmniRoute (`v3.8.52`) currently duplicates 35+ environment variables and the `qdrant` service definition inside `/Users/androidteam/Omniroute/docker-compose.override.yml`, sets `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS=true` (which sets `getProviderOutboundGuard()`, `getProviderValidationGuard()`, and `embeddingUrlGuard()` to `"none"` and disables cloud-metadata SSRF checks even though the default `OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS=true` already permits Host Ollama in `"block-metadata"` mode), leaves `# API_HOST=0.0.0.0` commented out in `.env:L69`, leaves three runtime resilience flags (`EMPTY_STREAM_SIBLING_RECOVERY_ENABLED`, `STREAM_READINESS_STALL_RETRY`, `DB_HEALTHCHECK_STARTUP_DEFERRED_ENABLED`) only in container env rather than SQLite `feature_flags`, and keeps 14 additional `v3.8.52` coding-agent feature flags disabled at their conservative defaults alongside `sessionAffinityTtlMs: 0`. Furthermore, on this 16 GiB Mac Mini (`hw.memsize = 17,179,869,184` bytes), Docker Desktop is configured with `MemoryMiB: 6144` (`~/Library/Group Containers/group.com.docker/settings-store.json:L25`, `MemTotal = 6,210,043,904` bytes / ~5.78 GiB), and `omniroute-base` currently lacks a container `mem_limit` (`process.constrainedMemory()` returns `2^64`). Consolidating configuration into the 3-tier hierarchy (per-subsystem SQLite/env authority -> `.env` process contract -> minimal structural `docker-compose.override.yml` with zero `environment:` overrides), pairing `OMNIROUTE_MEMORY_MB=4096` with `mem_limit: 5g` and single-heavyweight admission (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=1`) per `DOCKER_GUIDE.md:L331` (`heap < container memory <= VM RAM`), and enabling the 25 verified `feature_flags` plus `compression.mcpDescriptionCompressionEnabled` maximizes `v3.8.52` capabilities safely across upgrades.

## What Changes

- **Minimal Structural `docker-compose.override.yml` (Zero `environment:` Overrides), Lean `.env` Contract & Capacity-Gated Memory Sizing**:
  - Move process-level runtime, Qdrant (`QDRANT_VECTOR_SIZE=1024`, `QDRANT_HNSW_EF_CONSTRUCT=128`), hybrid memory (`MEMORY_VEC_QUANTIZATION=int8`, `MEMORY_RRF_K=60`, `OMNIROUTE_DEFAULT_OWNER_ID=6a72d8ab-88db-4d49-973b-864c6cbdace5`), semantic-cache cold-boot (`OMNIROUTE_SEMANTIC_CACHE_*`), SQLite diagnostic (`OMNIROUTE_SQLITE_SLOW_MS=200`, `OMNIROUTE_SKIP_DB_HEALTHCHECK=1`, `OMNIROUTE_MAX_TOOLS_LIMIT=256`), call/proxy-log retention (`CALL_LOG_MAX_ENTRIES=2000`, `CHAT_LOG_MAX_BODY_KB=256`, `CALL_LOGS_TABLE_MAX_ROWS=25000`, `PROXY_LOGS_TABLE_MAX_ROWS=25000`), heavyweight admission count-cap enforcement (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=1`), and port-binding (`API_HOST=0.0.0.0`) variables out of `/Users/androidteam/Omniroute/docker-compose.override.yml` and into `/Users/androidteam/Omniroute/.env` (loaded via `env_file: .env`), omitting `QDRANT_ENABLED`, `QDRANT_HOST`, `QDRANT_PORT`, and `QDRANT_COLLECTION` which resolve from SQLite `settings` first.
  - Size `omniroute-base` for the workstation's 6 GiB Docker Desktop VM (`MemoryMiB: 6144`, `MemTotal = 6,210,043,904` bytes / ~5.78 GiB on the 16 GiB Mac Mini) by setting `OMNIROUTE_MEMORY_MB=4096` in `.env` paired with `mem_limit: 5g` on `omniroute-base` in `docker-compose.override.yml` and `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=1` (`4096` MB V8 old-space < `5g` container cgroup ceiling < `5.78 GiB` VM RAM, leaving ~1 GiB for off-heap buffers/SQLite inside `omniroute` and ~800 MiB for `omniroute-qdrant` and `omniroute-redis`).
  - Shrink `docker-compose.override.yml` to a structural overlay with zero `environment:` overrides (Hub image `diegosouzapw/omniroute:latest`, explicit container `mem_limit` above `OMNIROUTE_MEMORY_MB`, `extra_hosts: ["host.docker.internal:host-gateway"]`, named volume `omniroute-data:/app/data`, `container-entrypoint-compat.sh` mount, relaxed healthcheck `timeout: 15s` and `start_period: 120s`, `redis` `ports: !reset []`, and `qdrant` `profiles: !override [base, memory]` + `/dev/tcp/127.0.0.1/6333` healthcheck while preserving upstream service identities `omniroute`, `omniroute-redis`, `omniroute-qdrant`, and volume `omniroute-qdrant-data`).
- **Per-Subsystem Authority Alignment, SSRF Metadata Guard Restoration, 25 SQLite Feature Flags & Official MCP Description Compression**:
  - Align configuration with each subsystem's actual code precedence (`feature_flags`: `SQLite > env > default`; `qdrant`: `SQLite settings > env > default`; `semanticCache`: `process.env.OMNIROUTE_SEMANTIC_CACHE_* > registered SQLite database_settings.cache > default`), keeping overlapping `OMNIROUTE_SEMANTIC_CACHE_*` values in `.env` and `PUT /api/settings/cache-config` synchronized so `/v1/responses`-first and `/v1/messages`-first cold starts initialize `SemanticCacheManager` without new JS bootstrap patches.
  - Remove `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS` (`effectiveValue: "false"`) while keeping `OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS="true"` so provider validation and embedding endpoints enforce `"block-metadata"` SSRF protection (blocking cloud metadata while permitting Host Ollama); note that `/v1/search` independently skips unconfigured default SearXNG (`http://localhost:8888/search`) via `isUnconfiguredLoopbackSearchProvider` in `open-sse/config/searchRegistry.ts:507-513`.
  - Persist 25 verified `v3.8.52` coding-agent feature flags as `"true"` and `ANTIGRAVITY_ACCOUNT_LEASE_ENABLED` as `"false"` in SQLite `feature_flags` (`source: "db"`; exact 25-key inventory in `design.md`), configure `mcpDescriptionCompressionEnabled: true` via the authoritative `PUT /api/settings/compression` endpoint (`key_value` `namespace = 'compression'`, rather than `feature_flags`, which `open-sse/mcp-server/server.ts:138-148` does not read), and set `sessionAffinityTtlMs: 300000` via `PATCH /api/settings`.
- **Retain Full High-Value Feature Stack & Enforce Behavioral Verification Gates**:
  - Retain Qdrant (`Tier-2` HNSW + scalar `int8` with `rescore: true`) + `sqlite-vec` (`Tier-1` `int8` fallback) + `memory_fts` BM25 RRF (`k=60`) + `voyage-ai/rerank-2.5` reranking, All-Request Redis Layer-2 Semantic Cache (`ct:<sha256_16>` + `tc:<sha256_16>` partition hashing + Host Ollama `nomic-embed-text` `768d`), `/v1/responses` `instructions` memory injection, and the 12 fail-closed chunk marker assertions in `scripts/container-entrypoint-compat.sh` and `scripts/update.sh`, with pre-deployment snapshots and behavioral gates for cold starts, tool-contract cache isolation, SSRF blocking, stale-step pruning, and session affinity.
