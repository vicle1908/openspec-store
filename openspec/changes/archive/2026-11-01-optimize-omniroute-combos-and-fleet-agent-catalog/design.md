## Decisions

### Decision 1: In-Place `R44` Non-Shell Tool Protection in `adaptBodyForCompression()`

- **Choice**: Update replacement rule `R44` in `/Users/androidteam/Omniroute/scripts/container-entrypoint-compat.sh` (targeting `14211.js`, `41669.js`, `72459.js`, `88137.js`, and `98542.js`) from:
  `c.tool_call_id=k;c._rtkSkip=!a.eligible`
  to:
  `c.tool_call_id=k;c._toolCommand=_cmd;c._rtkSkip=!_sh||!a.eligible` (where `_sh=/\b(bash|shell|terminal|run_command|execute_command|exec|command)\b/.test(_tn)`)
  while keeping the existing `responses_tool_call_id_*` fail-closed markers (`pattern: "c.tool_call_id=k;c._toolCommand=_cmd;c._rtkSkip=!_sh||!a.eligible"`) satisfied as a prefix substring, and add `"eval"`, `"task"`, `"todo"`, `"find"`, `"ask"`, `"lsp"`, `"ast_grep"`, and `"ast_edit"` to `codexResponsesConfig.preserveToolNames` in SQLite `key_value` (`namespace = 'compression'`).
- **Rationale**: In `14211.js`, `adaptBodyForCompression()` deletes `t.input` when converting OpenAI Responses `input[]` into `messages[]`. When `rtk` (`53846.js` / `72459.js`) runs afterward, `a.input` is already `undefined`, so `toolCallLookup` (`m`) is empty and `z(d, m)` returns `skipFilters: false` unless `a._rtkSkip` was already set to `true` by `adaptBodyForCompression()`. Because `g` inside `adaptBodyForCompression()` already maps every `call_id -> function_call.name`, testing `g.get(k)` directly in `R44` guarantees that only true shell tools (`bash`, `shell`, `terminal`, `run_command`, `execute_command`, `exec`, `command`) run RTK log filters while all other tools (`eval`, `task`, `todo`, `mcp__*`, file tools) set `c._rtkSkip = true`. Moreover, keeping `"c.tool_call_id=k;c._rtkSkip=!a.eligible"` as the prefix preserves the exact `51` modification / `60` marker ledger across `24` compiled files.
- **Alternatives Considered**: Passing `a.input` into `53846.js` without deleting `t.input` — rejected because downstream compression stages expect `messages[]` only when `adapted: true`.

### Decision 2: SQLite Combo & OMP `agent.db` Transaction Boundaries

- **Transaction Boundaries**:
  1. **OmniRoute SQLite (`omniroute-data` `/app/data/storage.sqlite`)**: Snapshot `combos` and `key_value` (`namespace = 'compression'`) to `~/.omniroute/backups/optimize-omniroute-combos-and-fleet-agent-catalog/omniroute-storage-pre.json` (`mode 0600`) before mutation. Apply combo updates via authenticated `PUT http://127.0.0.1:20128/api/combos/{id}` (spreading `...current` and `...current.config` so `sqliteComboRepository.ts` shallow merge never drops nested `config` keys) and `PUT http://127.0.0.1:20128/api/settings/compression` inside atomic SQLite transactions.
  2. **OMP Credential Database (`~/.omp/agent/agent.db`)**: Copy a read-only `.backup` snapshot to `~/.omniroute/backups/optimize-omniroute-combos-and-fleet-agent-catalog/omp-agent.db.bak` (`mode 0600`), then execute `BEGIN IMMEDIATE; DELETE FROM auth_credential_blocks WHERE credential_id IN (SELECT id FROM auth_credentials WHERE provider='google-antigravity' AND identity_key='email:ascenddevtwo@gmail.com'); DELETE FROM auth_credentials WHERE provider='google-antigravity' AND identity_key='email:ascenddevtwo@gmail.com'; COMMIT;` and verify `PRAGMA integrity_check` returns `ok` and `COUNT(*) == 14`.
  3. **External Host Configuration Files (16 Surfaces)**: Before mutating any file under `/Users/androidteam/`, copy a mode-`0600` backup and record its pre-mutation SHA-256 and file mode (`stat -L -f '%04Lp'`) in `~/.omniroute/backups/optimize-omniroute-combos-and-fleet-agent-catalog/manifest.json`. Verify pre-write SHA-256 equality immediately before writing to a sibling `.tmp` file (`0600` for provider/credential configs; `0644` for `~/.codex/cockpit-model-catalog.json`), validate syntax (`jq`, `tomllib`, `yaml`), and atomically replace via `os.replace()`.

## Risks / Trade-offs

- **Risk: Container recreate detaching single-file bind mount (`container-entrypoint-compat.sh`)** → **Mitigation**: After updating `/Users/androidteam/Omniroute/scripts/container-entrypoint-compat.sh` on the host, recreate the container via `docker compose --profile base up -d --no-build --pull never --no-deps --force-recreate omniroute-base` and run `/Users/androidteam/Omniroute/scripts/ensure-muse-wire-compat.sh` to verify all `51` modifications and `60` fail-closed markers across `24` compiled files.
- **Risk: Factory Droid (`droid`) resetting `~/.factory/settings.json` permissions to `0644` at runtime** → **Mitigation**: Re-apply `chmod 0600 ~/.factory/settings.json` after running `droid exec` verification probes and verify with `stat -L -f '%04Lp'`.
- **Risk: Credential exposure when editing `~/.kimi-code/config.toml` or `~/.cline/data/settings/providers.json`** → **Mitigation**: Perform value-blind in-memory parsing and serialization (`skill://value-blind-config-audit`) that preserves existing `api_key` / `apiKey` fields byte-for-byte without printing or logging them.
