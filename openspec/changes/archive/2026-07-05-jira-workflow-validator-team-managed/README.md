# jira-workflow-validator-team-managed

Extend the `jira-workflow-validator` capability to (a) support team-managed project workflows against the new unified editor (default since March 2026), (b) cover transition creation entry points, and (c) add a server-side validate pre-flight. Supersedes `jira-code-review-field-validation`.

See `proposal.md` for the why, `design.md` for the architecture, `specs/jira-workflow-validator/spec.md` for the canonical requirements, and `tasks.md` for the implementation checklist.
