# Proposal: MCP Router Runtime Hygiene and Lockfile Reconciliation

## Why

Recent workspace activity in `~/Developer/platform/mcp-router` left an uncommitted working tree diff:
1. `pnpm-lock.yaml` drifted with 158 lines at the top representing `pnpm@12.14.0`'s native multi-document `packageManagerDependencies` YAML header (`pnpm/crates/env-installer`). Commit `7bce8df` upgraded `platform/mcp-router/package.json:13` to `"packageManager": "pnpm@12.14.0"`, but omitted the corresponding lockfile header recording `pnpm@12.14.0` and its 14 optional `@pnpm/exe.<platform>@12.14.0` integrity hashes. Reverting `pnpm-lock.yaml` breaks `pnpm install --frozen-lockfile` with `ERR_PNPM_FROZEN_LOCKFILE_WITH_OUTDATED_LOCKFILE`. Furthermore, legacy `npx pnpm@10.22.0` must NOT be used: it detects `"packageManager": "pnpm@12.14.0"`, attempts to self-switch to `~/Library/pnpm/.tools/pnpm/12.14.0/bin/pnpm` (which contains only a 35-byte stub), and crashes with `ENOENT`.
2. An untracked `.graphify/` directory containing `.graphify/needs_update` was generated by `.git/hooks/post-rewrite` (`graphify_mark_stale()`) because `.graphify/` is missing from `platform/mcp-router/.gitignore`.
3. Six tracked `graphify-out/` files (`graph.json`, `graph.html`, `GRAPH_REPORT.md`, `manifest.json`, `.graphify_labels.json`, `.graphify_labels.json.sig`) were regenerated by `.git/hooks/post-commit` following commit `abb7c11`. `platform/mcp-router/.gitignore:88-98` already properly ignores ephemeral cache files (`graphify-out/cache/`, `graphify-out/.graphify_*`, `graphify-out/needs_update`, `graphify-out/.graphify_root`, `graphify-out/.rebuild.lock`, `graphify-out/20*/`) while intentionally tracking core graph models and reports.

These uncommitted changes trigger false positives during repository clean-tree checks, CI validations, and multi-repo git status audits.

## What Changes

- Reconcile and validate `pnpm-lock.yaml` using host `pnpm install --frozen-lockfile` (`pnpm@12.14.0`), verifying that the multi-document `packageManagerDependencies` header completes commit `7bce8df` with no unexpected workspace dependency drift.
- Update `platform/mcp-router/.gitignore` to add `.graphify/` while preserving existing `graphify-out/` tracking and negation rules.
- Remove untracked `.graphify/` directory and stage the 6 regenerated tracked `graphify-out/` files (`graph.json`, `graph.html`, `GRAPH_REPORT.md`, `manifest.json`, `.graphify_labels.json`, `.graphify_labels.json.sig`).
- Commit all reconciled hygiene changes with `GRAPHIFY_SKIP_HOOK=1` to prevent the post-commit hook from spawning an asynchronous rebuild that re-dirties `graphify-out/`, and verify a clean working tree.
- Validate workspace test, typecheck, and build gates using host `pnpm@12.14.0` (`pnpm -r test`, `pnpm typecheck`, `pnpm build`).

## Capabilities / Scope

- External Repository Root: `~/Developer/platform/mcp-router` (governed externally relative to `platform/openspec-store`).
