# Design: MCP Router Runtime Hygiene and Lockfile Reconciliation

## Context

`platform/mcp-router` is an external repository root (relative to `platform/openspec-store`) housing `@mcp_router/shared`, `@mcp_router/cli`, `@mcp_router/electron`, and related monorepo packages.
Commit `7bce8df` (`2026-10-17-package-and-deploy-mcp-router-v0-6-4-runtime`) pinned the toolchain in `platform/mcp-router/package.json:13` to `"packageManager": "pnpm@12.14.0"`.

Subsequent repository inspection revealed two distinct hygiene issues:
1. **pnpm Lockfile Multi-Document Header Drift**: Native Rust `pnpm@12.14.0` generated a 158-line multi-document YAML header (`packageManagerDependencies` section via `pnpm/crates/env-installer`) recording `pnpm@12.14.0` and 14 optional `@pnpm/exe.<platform>@12.14.0` integrity hashes. Commit `7bce8df` updated `package.json` but omitted staging this header. Reverting `pnpm-lock.yaml` breaks `pnpm install --frozen-lockfile` with `ERR_PNPM_FROZEN_LOCKFILE_WITH_OUTDATED_LOCKFILE`. Running legacy `npx pnpm@10.22.0` fails catastrophically with `ENOENT` because pnpm 10 reads `"packageManager": "pnpm@12.14.0"` and attempts to self-switch to an unpopulated executable stub at `~/Library/pnpm/.tools/pnpm/12.14.0/bin/pnpm`.
2. **Graphify Working Tree Dirty State**: `.git/hooks/post-rewrite` (`graphify_mark_stale()`) wrote `.graphify/needs_update`, leaving an untracked `.graphify/` directory because `.graphify/` was omitted from `.gitignore`. Concurrently, `.git/hooks/post-commit` regenerated the 6 tracked core graph files (`graph.json`, `graph.html`, `GRAPH_REPORT.md`, `manifest.json`, `.graphify_labels.json`, `.graphify_labels.json.sig`) following commit `abb7c11`. `platform/mcp-router/.gitignore:88-98` already properly ignores ephemeral cache entries (`graphify-out/cache/`, `graphify-out/.graphify_*`, `graphify-out/needs_update`, `graphify-out/.graphify_root`, `graphify-out/.rebuild.lock`, `graphify-out/20*/`) while intentionally tracking the core graph knowledge base.

## Decisions

### D1: Accept and Validate Native pnpm@12.14.0 Multi-Document Header
Do NOT revert `pnpm-lock.yaml` and NEVER invoke `npx pnpm@10.22.0`.
- Validate the multi-document lockfile using the host binary: `/opt/homebrew/bin/pnpm install --frozen-lockfile` (`pnpm@12.14.0`).
- Inspect `git diff pnpm-lock.yaml` to verify that the +158 lines consist strictly of the `packageManagerDependencies` document header for `pnpm@12.14.0` and its 14 optional `@pnpm/exe.*` platform packages, ensuring zero unexpected workspace dependency drift.
- Stage and commit `pnpm-lock.yaml` to complete the toolchain migration introduced in commit `7bce8df`.

### D2: Ignore Rule Hardening & Tracked Graphify Reconciliation
- Update `platform/mcp-router/.gitignore` to add `.graphify/`, preventing post-rewrite hooks from leaving untracked sentinel markers. Preserve existing lines 88–98 that govern `graphify-out/cache/`, `graphify-out/.graphify_*`, `needs_update`, and the tracked negation rules.
- Remove the untracked `.graphify/` directory from the working tree.
- Reconcile and stage the 6 tracked `graphify-out/` files (`graph.json`, `graph.html`, `GRAPH_REPORT.md`, `manifest.json`, `.graphify_labels.json`, `.graphify_labels.json.sig`) regenerated by `.git/hooks/post-commit`.
- Commit the reconciled hygiene changes using `GRAPHIFY_SKIP_HOOK=1` (`GRAPHIFY_SKIP_HOOK=1 git commit ...`). This environment variable silences the post-commit hook from launching an asynchronous rebuild that would immediately re-dirty `graphify-out/`.
- Verify `git status --porcelain` is completely clean.

### D3: Monorepo Verification Suite with Host pnpm@12.14.0
Execute full monorepo verification using the canonical host toolchain (`pnpm@12.14.0`):
1. `pnpm -r test`
2. `pnpm typecheck`
3. `pnpm build`

Confirm zero regressions across all workspace projects (`@mcp_router/shared`, `@mcp_router/cli`, `@mcp_router/electron`, etc.).
Note that because this change is purely runtime/tooling hygiene in an external repository root without interface modifications, delta specs are skipped (`skip_specs: true`).
