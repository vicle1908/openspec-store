## Decisions

### 1. Reconcile Live SQLite Combos with Full `current.config` Preservation and Pure 15-Step Opus Pool
- **Decision**: During `/opsx:apply`, capture a pre-mutation JSON backup of `combos` (`gemini-3.8-flash-high`, `claude-opus-5.5`, `claude-sonnet-5.5`), then update each combo while preserving its full `current.config` object (`config: { ...current.config, ... }` — required because `updateCombo` in `sqliteComboRepository.ts:234-239` performs a shallow top-level merge `const merged = { ...current, ...data }` that would otherwise overwrite nested `config` fields):
  - `gemini-3.8-flash-high` (`7555d851-b4f3-44c6-b1fb-c6fdceabf388`): set `"context_cache_protection": false` in `combos.data` and `context_cache_protection = 0` on the row, preserve `current.config`, and include all **12 active `g1-pro-tier` `agy` connections** (`ea0d6c23-85c0-42c8-abdf-8186effd3371`, `38782750-7a60-46d4-ae3f-e8c13cda296b`, `a59369ac-c8a9-40f7-ad21-fc7c7bc7a4a9`, `9d66311f-9db7-49b2-90f5-277c5f311f2a`, `615a4993-68ce-4a6b-be58-ed376be8ae63`, `20369f65-4fae-4fa0-b02b-4f15047bee79`, `d5c3465f-9797-4b4b-a937-c3e653e168fb`, `d71506bf-5952-4805-82e0-125cef2941ce`, `cdac4585-b65a-4134-aa11-9544f7e42245`, `ce95e1cb-27a4-433f-9c50-bdb6ad0b6b6b`, `d902fb26-520d-4316-9f2c-6e52c5da7b74`, `e85dd569-0271-4974-bcd9-b250295e6810`) with non-empty email `label`s while excluding all 3 `g1-ultra-tier` accounts (`62af823b-f3d7-4e6b-87a9-98069167d4f6`, `0532bad4-2486-4286-8f06-510e9c678620`, `338764b8-1cd7-4946-b789-ee5dad4c5073`) and banned account `47f334b1-b801-41f6-a709-4ebabb7a86d6`.
  - `claude-opus-5.5` (`4b2430da-0b3b-4b0e-9773-ec0f97adc252`): replace banned step `[4]` (`47f334b1-b801-41f6-a709-4ebabb7a86d6` / `vicgnome19091@gmail.com`) with active Pro connection `e85dd569-0271-4974-bcd9-b250295e6810` (`hongsonle19081952@gmail.com`) across the 15 `agy/claude-opus-4-6-thinking` `kind: "model"` steps (`12` active Pro + `3` active Ultra) with **`0` `combo-ref` steps**, preserving full `current.config` (`strategy: "auto"`, `nestedComboMode: "flatten"`, `context_cache_protection: false`, `targetTimeoutMs: 180000`, `predictiveTtftMs: 60000`).
  - `claude-sonnet-5.5` (`9447399c-856b-4f52-8820-b3bf3dc3f132`): replace banned step `[4]` (`47f334b1-b801-41f6-a709-4ebabb7a86d6` / `vicgnome19091@gmail.com`) with active Pro connection `e85dd569-0271-4974-bcd9-b250295e6810` (`hongsonle19081952@gmail.com`) across the 15 `agy/claude-sonnet-4-6` `kind: "model"` steps (`12` active Pro + `3` active Ultra), preserving full `current.config` (`strategy: "auto"`, `nestedComboMode: "flatten"`, `context_cache_protection: false`, `targetTimeoutMs: 120000`, `predictiveTtftMs: 45000`, `maxRetries: 1`).
- **Rationale**: Prevents `strategy: "auto"` + `nestedComboMode: "flatten"` from inlining `gemini-3.8-flash-high` into `claude-opus-5.5` and hijacking Opus requests, eliminates banned connection `47f334b1-b801-41f6-a709-4ebabb7a86d6`, and preserves all nested `config` fields.

### 2. Preserve Exact `### Requirement:` and `#### Scenario:` Headers in Delta Specs While Tightening Bodies `<= 485` Characters
- **Decision**: Keep every existing `### Requirement:` and `#### Scenario:` title verbatim in `specs/*/spec.md` under `## MODIFIED Requirements`, tighten the 11 over-length requirement paragraphs across `omniroute-runtime-customization` (2), `omniroute-closure-integrity` (1), and `omniroute-agent-cli-routing` (8) to `<= 485` characters, and update all drifted scenario bullet clauses across `omniroute-compression-and-routing` and `omniroute-agent-cli-routing`.
- **Rationale**: `openspec validate` and `openspec archive` require `## MODIFIED Requirements` to retain exact requirement and scenario headers while replacing the block in place.

## Risks / Trade-offs

- **Risk**: Shallow top-level merge in `PUT /api/combos/{id}` (`sqliteComboRepository.ts:234-239`) overwrites `current.config` if a caller passes only `{ targetTimeoutMs, predictiveTtftMs }`.
  - **Mitigation**: Read `GET /api/combos/{id}` first and spread `...current.config` when constructing the `PUT /api/combos/{id}` payload, then verify all `config` keys (`candidatePool`, `zeroLatencyOptimizationsEnabled`, `hedging`, `fallbackCompressionMode`, `resetWindowQuotaCacheTtlMs`, `resetAwareQuotaCacheTtlMs`, `targetTimeoutMs`, `predictiveTtftMs`) on readback.
