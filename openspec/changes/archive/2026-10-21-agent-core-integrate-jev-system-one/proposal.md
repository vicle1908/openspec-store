# Proposal: Integrate TypeSafe Jev System One into SHB Banking Ecosystem & Workspace Foundation

## Why

Discrete decision-making across banking agent workflows currently incurs excessive latency and token expenditure by forcing full autoregressive LLM generations or relying on brittle regex patterns for security-critical authorizations. In the Saigon-Hanoi Bank (SHB) Banking Ecosystem (`~/Developer/shb/*`), tool authorization guards, anti-money laundering (AML) pre-flight triage, 12-stage LangGraph harness routing, engineering skill dispatch, stage deliverable verification, and evaluation judges repeatedly either incur multi-second token generation latency or fall back to rigid regex pattern matching that misses obfuscated prompt injection, structuring behaviors, and transliterated sanctions evasions.

TypeSafe's Jev is a dedicated System One model: it evaluates typed questions against a state and returns typed values and calibrated probabilities ($p \in [0, 1]$) that application code branches on directly — without autoregressive text generation, token streaming, or output-token parsing overhead. Integrating Jev into `shb-core` establishes a unified, shared workspace foundation that provides fast semantic pre-flight guardrails, dynamic tool schema pruning, confidence-gated LangGraph harness skips, two-stage candidate skill reranking, non-generative trace evaluation scoring, and unified OpenTelemetry decision observability across the seven core SHB banking packages (`shb-core`, `shb-agent-core`, `shb-agent-harness`, `shb-ai-harness-skills`, `shb-agent-skills`, `shb-observability`, and `shb-ai-review`), with alignment to `shb-mcp-servers` and `shb-tools`, serving simultaneously as an ecosystem blueprint reusable across other multi-repo workspace organizations (`platform`, `vds`, `ascend`, `ghtk`, `fpt`).

### Non-Goals

- **Freezing `tdt/agent-core` and `tdt-core`**: The entire `~/Developer/tdt/agent-core` codebase, `tdt-core`, and `~/.tdt/` environment are strictly out of scope and frozen for this change. No files in `tdt/*` will be modified, inspected, or imported.
- **Never Bypassing Maker-Checker Invariants**: Transfers strictly exceeding the 50,000,000 VND maker-checker threshold (`MAKER_CHECKER_THRESHOLD_VND`) ALWAYS require supervisor token validation (`ModelRetry` / `PENDING_APPROVAL`). Jev is an early semantic risk classifier for sub-threshold escalation and pre-flight blocking; it NEVER bypasses or overrides mandatory maker-checker supervisor approvals.
- **Never Bypassing LangGraph Human-in-the-Loop Gates**: The LangGraph 12-stage harness's `interrupt()` gate at `StageName.PLAN_REVIEW` remains an inviolable human checkpoint. Jev decisions only govern conditional workflow edge skips (such as bypassing `StageName.API_CONTRACT` directly to `StageName.DESIGN` on high-confidence spec decisions) and never bypass human review.
- **No Generative or Streaming Text**: Jev is strictly a System One decision evaluator emitting calibrated probabilities, choices, and ordinal scores. Generative text generation, streaming chat protocols, and explainability narratives remain the sole domain of downstream generative models (such as Pydantic AI agent models).
- **No Unbounded Live Network Calls in Default CI/Unit Suites**: While `TYPESAFE_API_KEY` is provisioned in `~/.zshenv` (`mode 0600`) and all decision contracts, thresholds, and state-referenced question framings have been empirically validated and calibrated live against `https://api.typesafe.ai` (`jev-1.13.0` and `jev-1.14.0` over HTTP/2 in `213ms–298ms`, `client.models.list()` returning `jev-latest` and `jev-preview`, and `pydantic-ai==2.54.0` `TypeSafeModel("jev-1.13.0")`), default `pytest` suites remain strictly hermetic via mock `httpx2` transports and `allow_env_file_fallback=False` / `JEV_DISABLE_ENV_FILE_FALLBACK=1`, with live API smoke verification gated behind opt-in `SHB_RUN_LIVE_JEV_TESTS=1` (or `shb doctor`) and executed value-blindly without ever logging or printing the credential.

## What Changes

This change delivers a coordinated 4-layer integration across the SHB Banking Ecosystem and Workspace Foundation:

### Layer 1 — Shared Ecosystem Foundation (`shb-core`, package `shb_core`)

- **Configuration & Environment Isolation (`src/shb_core/config.py`)**:
  - Adds `JevSettings(BaseSettings)` loading from `~/.shb/.env` and process environment variables with `AliasChoices` supporting both `JEV_` and `SHB_JEV_` prefixes, strictly isolated from `~/.tdt/`.
  - Uses a concise `@model_validator(mode="before")` (`_strip_jev_secrets`) on `JevSettings` and `ShbSettings` to strip any `typesafe_api_key` or `pydantic_ai_gateway_api_key` key passed in an input/config dictionary and emit a `UserWarning` (without adding an unused `~/.shb/config.yaml` file loader to `src/shb_core/config.py`).
  - Attaches `jev: JevSettings = Field(default_factory=JevSettings)` onto `ShbSettings` accessible via `get_settings().jev`, and updates `reset_settings()` (`src/shb_core/config.py:82`) to invoke `reset_jev_client()` via a lazy import (`from shb_core.jev import reset_jev_client`) so importing `shb_core.config` never creates a circular import with `shb_core.jev`.
  - Pinned default fields: `enabled: bool = False`, `model: str = "jev-1.13.0"` (with forward compatibility for preview `jev-1.14.0` in `typesafe-sdk>=0.7.5`), `timeout_seconds: float = 1.5`, `max_retries: int = 2`, `http2: bool = True`, `base_url: str | None = None`, `fail_closed: bool = True`, `circuit_breaker_threshold: int = 3`, `circuit_breaker_cooldown_seconds: float = 30.0`.
  - **Request Body Compression & Gateway/Version Compatibility**: Exposes `compression: Literal["zstd", False] | None = None`. While `typesafe-sdk>=0.7.5` enables `zstd` request body compression by default for bodies $\ge 1\text{ KiB}$, cached `typesafe-sdk==0.7.2` (`typesafe_sdk/_core/client/sync/client.py:21-33`) does not accept a `compression` keyword argument (`TypeError: unexpected keyword argument 'compression'`), and non-official proxy gateways (`PYDANTIC_AI_GATEWAY_API_KEY` / custom `base_url`) or mock `httpx2` transports may not decompress `Content-Encoding: zstd`. `JevDecisionClient` resolves `effective_compression = False if (base_url or transport is not None) else settings.jev.compression`, stores it on the wrapper, and passes `compression=effective_compression` to `TypeSafeClient` / `AsyncTypeSafeClient` **only when `"compression" in inspect.signature(TypeSafeClient.__init__).parameters`**.
- **CLI Diagnostics & Configuration Display (`src/shb_core/cli.py:14-43`, `tests/test_cli.py`)**:
  - Updates `config_show()` in `src/shb_core/cli.py` to print non-sensitive `SHB_JEV_ENABLED={settings.jev.enabled}` and `SHB_JEV_MODEL={settings.jev.model}` alongside existing `SHB_*` fields.
  - Updates `doctor()` in `src/shb_core/cli.py` to report value-blind Jev diagnostics (`settings.jev.enabled`, `settings.jev.model`, `settings.jev.http2`, `resolved_base_url`, credential provisioned boolean + length + 8-char SHA-256 prefix + `~/.zshenv` `0600` mode check via `_resolve_endpoint_and_api_key()`, `get_jev_client().circuit_breaker` state, and opt-in live ping when `SHB_RUN_LIVE_JEV_TESTS=1` or `--live-jev` is passed) without ever printing raw secrets.
- **System One Decision Client (`src/shb_core/jev.py`)**:
  - Implements `JevDecisionClient` wrapping official `typesafe_sdk.TypeSafeClient` and `typesafe_sdk.AsyncTypeSafeClient` (`evaluate` and `a_evaluate` calling `system_one`), alongside a process-wide cached `get_jev_client() -> JevDecisionClient` and `reset_jev_client() -> None` singleton (invoked automatically via lazy `from shb_core.jev import reset_jev_client` in `shb_core.config.reset_settings()`) so HTTP/2 connection pools and circuit-breaker state persist across tool calls and LangGraph stage transitions. `JevDecisionClient` lazily instantiates its synchronous `TypeSafeClient` (`evaluate`) and asynchronous `AsyncTypeSafeClient` (`a_evaluate`), recording `_async_loop_id = id(asyncio.get_running_loop())` when creating `AsyncTypeSafeClient` and automatically recreating `AsyncTypeSafeClient` (`httpx2.AsyncClient`) whenever `id(asyncio.get_running_loop()) != self._async_loop_id` (while preserving the shared `JevCircuitBreaker` state) to prevent `RuntimeError: Event loop is closed` across multiple `pytest` async tests or repeated `asyncio.run()` calls. Defines only the minimal optional-dependency fallback shims (`Noul`, `Choice`, `Score`, `NoulCriteria`, `SystemOneResponse`, `TypeSafeError`, `TypeSafeAuthenticationError`) in **one place** (`src/shb_core/jev.py`, imported by `src/shb_core/decisions.py`) instead of duplicating 12 classes across two files.
  - Supports TypeSafe's three real primitives and calibrated confidence math (`docs.typesafe.ai/confidence.md`, `primitives.md`):
    - `NoulAnswer`: Exposes `noul: float` ($p \in [0.0, 1.0]$) with certainty $|2p - 1|$. A score near $0.5$ indicates maximal uncertainty between yes and no, NOT medium intensity.
    - `Choice(criteria=Mapping[str, JSONContent | None])`: Supports `None` for self-explanatory keys or pre-parsed candidate spans (`typesafe_sdk/_core/question_types.py`). `ChoiceAnswer.confidence` measures distribution concentration.
    - `Score(criteria=Sequence[JSONContent])`: 0-indexed levels $0 \dots N-1$ (`min_length=2`), returning expected value $\sum_{i=0}^{N-1} i \cdot P(i) \in [0.0, N-1]$ (`ScoreAnswer.score`, `confidence`, `probabilities`, `legend`).
  - **Caller-Only Question IDs & Structured `JSONContent` with Backticked State Paths (`docs.typesafe.ai/concepts/state.md`)**:
    - Question IDs are for caller code only and are never sent to the model. Questions carry self-contained meaning in `instructions` and `criteria` using structured `JSONContent` dicts (`{"definition": ..., "includes": [...], "excludes": [...], "contrast_with": ...}`) for nuanced domain boundaries.
    - Instructions use backticked JSON state paths (e.g., `` `transaction.narrative` ``, `` `beneficiary.name` ``, `` `ticket.stage_results.spec.summary` ``) to focus model attention on nested state attributes.
  - **Token Attribution & Normalized `JevUsage` (`response.usage`)**:
    - In `typesafe-sdk` (`0.7.2` and `0.7.5`, `typesafe_sdk/_core/response_types.py:59-67` and `typesafe_sdk/_schemas/models.py:130-137`, re-exported as `typesafe_sdk.Usage`), `Usage` defines only `input_tokens: int | None = None` and `output_tokens: int | None = None` with `ConfigDict(extra="ignore", frozen=True, strict=True)` (it does not define `question_tokens` or `total_tokens` attributes). `JevDecisionClient` reads `input_tokens = response.usage.input_tokens or 0` and `output_tokens = response.usage.output_tokens or 0` from `typesafe_sdk.Usage`, and surfaces a clean `JevUsage(input_tokens: int = 0, output_tokens: int = 0)` model with `@property def total_tokens(self) -> int: return self.input_tokens + self.output_tokens` (without a duplicate `question_tokens` field) on the client's evaluation result, OpenTelemetry spans (`jev.input_tokens`, `jev.output_tokens`, `jev.total_tokens`), and `TelemetryStore`. Mock transport JSON bodies include `"usage": {"input_tokens": ..., "output_tokens": ...}`.
  - **Preserves Verified `typesafe-sdk` Runtime Invariants**:
    - **Endpoint-First Credential & Base URL Resolution (`JevDecisionClient._resolve_endpoint_and_api_key`)**: Because `pydantic_ai/providers/gateway.py:105-112` only supports `openai`, `groq`, `anthropic`, `bedrock`, and `google`/`google-cloud` (not a built-in `gateway/typesafe` route), proxy/gateway routing for Jev uses an explicit custom `base_url` (`settings.jev.base_url` or `TYPESAFE_BASE_URL`). `JevDecisionClient._resolve_endpoint_and_api_key()` resolves `resolved_base_url = base_url or settings.jev.base_url or os.environ.get("TYPESAFE_BASE_URL") or DEFAULT_BASE_URL` (`https://api.typesafe.ai`) **first** (normalizing trailing `"/"` and optional trailing `"/v1"` on `https://api.typesafe.ai` to `DEFAULT_BASE_URL` so `TYPESAFE_BASE_URL="https://api.typesafe.ai/v1"` stays in Direct Mode without doubling `/v1/v1/systemone`), then resolves only the matching credential:
      - **Direct Mode (`resolved_base_url == "https://api.typesafe.ai"`)**: Resolves `api_key` arg $\to$ `os.environ.get("TYPESAFE_API_KEY")` $\to$ `~/.shb/.env` `TYPESAFE_API_KEY` $\to$ `~/.zshenv` `TYPESAFE_API_KEY` (never sending `PYDANTIC_AI_GATEWAY_API_KEY` to `https://api.typesafe.ai`).
      - **Custom Proxy / Gateway Mode (`resolved_base_url != "https://api.typesafe.ai"`)**: Resolves `api_key` arg $\to$ `os.environ.get("PYDANTIC_AI_GATEWAY_API_KEY")` $\to$ `~/.shb/.env` `PYDANTIC_AI_GATEWAY_API_KEY` $\to$ `~/.zshenv` `PYDANTIC_AI_GATEWAY_API_KEY` $\to$ `TYPESAFE_API_KEY` fallback (for self-hosted TypeSafe proxies), so that when both `~/.zshenv` `TYPESAFE_API_KEY` and `PYDANTIC_AI_GATEWAY_API_KEY` + custom gateway `base_url` are set, the gateway key is sent to the gateway rather than overridden by `TYPESAFE_API_KEY`.
      - **Safe `~/.zshenv` Parsing & Env File Isolation**: When `allow_env_file_fallback=True` (default when `JEV_DISABLE_ENV_FILE_FALLBACK` is not set) and reading `~/.zshenv`, verifies `(zshenv_path.stat().st_mode & 0o022) == 0` (skipping `~/.zshenv` with a `UserWarning` if group- or world-writable) and parses matching `export TYPESAFE_API_KEY=...` / `export PYDANTIC_AI_GATEWAY_API_KEY=...` lines with `shlex.split(line, comments=True)` (ignoring values containing unexpanded `$` shell expressions) so inline `# comments` or quotes never corrupt the parsed key, while **strictly refusing** to read `~/.tdt/.env`. Unit tests exercising missing-credential fail-closed paths pass `allow_env_file_fallback=False` (or set `JEV_DISABLE_ENV_FILE_FALLBACK=1` via `monkeypatch`) so hermetic tests are never accidentally satisfied by the host's `~/.zshenv` key.
    - **HTTP/2 Transport Multiplexing & `h2` Package Availability Guard (`typesafe-sdk[http2]>=0.7.2`, `importlib.util.find_spec("h2")`)**: When `settings.jev.http2` is `True` and `transport is None`, `JevDecisionClient` computes `use_http2 = bool(settings.jev.http2 and importlib.util.find_spec("h2") is not None)` before instantiating `httpx2.AsyncClient(http2=use_http2, timeout=timeout)` / `httpx2.Client(http2=use_http2, timeout=timeout)` with configured `timeout_seconds` (so `httpx2` neither falls back to its internal 5.0s default nor raises `ImportError: Using http2=True, but the 'h2' package is not installed` in environments lacking `h2` / `hpack` / `hyperframe`, gracefully falling back to HTTP/1.1 with `timeout=timeout`). Exposes `close()` / `aclose()` methods and sync/async context manager protocols.
    - **Safe Request ID Extraction**: Defensively catches `TypeSafeError("The response did not include a request ID.")` (`typesafe_sdk/_core/schemas/base.py:67-73`) when the `x-typesafe-request-id` header is missing, reading `raw_http_response.headers.get("x-typesafe-request-id")` with a safe empty fallback.
    - **Native Pydantic Response Model Handling**: Custom typed schemas declaring top-level question fields subclass `SystemOneResponse` (whose `_decode()` lifts `decoded["answers"][field]` onto top-level model attributes, unlike plain `BaseModel`), while `JevDecisionClient` safely normalizes and lifts `answers` when a plain `BaseModel` is passed.
    - **Thread-Safe Consecutive Failure Circuit Breaker (`JevCircuitBreaker`), Event-Loop-Aware Async Pooling & Shared `get_jev_client()` Singleton**: Protected by `threading.Lock` and `time.monotonic()` in `src/shb_core/jev.py` and shared via the process-wide `get_jev_client()` singleton so HTTP/2 connection pools (`httpx2.Client` / `httpx2.AsyncClient`) and consecutive failure counts persist across tool calls (`initiate_fund_transfer`, `screen_beneficiary`) and LangGraph stage transitions (`_should_skip_api_contract`) instead of resetting to `0` on every call; lazily creates `TypeSafeClient` and `AsyncTypeSafeClient` and recreates `AsyncTypeSafeClient` whenever `id(asyncio.get_running_loop()) != self._async_loop_id` while preserving `JevCircuitBreaker` state; trips to open state after 3 consecutive transport or HTTP 5xx failures, failing closed or safe according to policy during a 30-second cooldown period before attempting half-open probe requests.
    - **Wire-Log Clamping & State Sanitization (`sanitize_jev_state`)**: Clamps `logging.getLogger("typesafe_sdk")` to `>= logging.INFO` to prevent `RequestState._log_wire` from logging raw request payloads at `DEBUG`. Implements `sanitize_jev_state(state: Any, *, max_tokens: int = 32_000) -> Any` in `src/shb_core/jev.py` using `shb_core.security.crypto.mask_pan` and recursive secret-key redaction (`secret`, `token`, `password`, `key`, `supervisor_approval_token`, excluding `_NON_SECRET_STRUCTURAL_KEYS` such as `idempotency_key` and `has_supervisor_token`) to enforce bounded (`<32k` tokens) and redacted state projections.
    - **Distributed Telemetry Spans**: Emits OpenTelemetry trace spans (`shb.jev.decision`) via `shb_core.telemetry.get_tracer("shb_core.jev")` with model, question count, latency, normalized token usage (`jev.input_tokens`, `jev.output_tokens`, `jev.total_tokens`), and outcome attributes.
- **Centralized Decision Registry & 6 Official Cookbook Patterns (`src/shb_core/decisions.py`)**:
  - Provides a single, centralized, code-reviewed module housing all atomic questions, structured `JSONContent` criteria, combining weights, empirically calibrated risk-scaled confidence thresholds (measured live on `jev-1.13.0` over HTTP/2), `AuthorityClass`, `GuardrailOutcome`, `GuardrailPolicy`, `TOOL_AUTHORITY_MAP`, `MCP_TOOL_AUTHORITY_MAP`, `is_valid_supervisor_token`, and the reusable `evaluate_guardrail_policy()` helper across the SHB ecosystem (strictly free of `SEC-001` secret-like literals $\ge 12$ chars or `PCI-001` unmasked 16-digit PANs in non-comment lines).
  - Defines portable foundation contracts and guardrail evaluators (`DecisionContract`, `AuthorityClass`, `GuardrailOutcome`, `GuardrailPolicy`, `TOOL_AUTHORITY_MAP`, `MCP_TOOL_AUTHORITY_MAP`, `is_valid_supervisor_token()`, `evaluate_guardrail_policy()`, `CitationCheckContract`) in `shb_core.decisions` (re-exported by `shb_agent.tools.guardrails`) so both `shb-agent-core` (`JevToolGuardrail`) and `shb-mcp-servers` (`src/shb_mcp/tools.py:173` `execute_tool`) evaluate pre-flight guardrails without `shb-mcp-servers` importing `shb_agent`, and so contracts remain reusable across workspace organizations (`shb`, `platform`, `vds`, `ascend`, `ghtk`, `fpt`, `wiki`).
  - Implements the 6 official TypeSafe cookbook patterns:
    1. **Speculative Fan-Out & Single-Pass Function Calling (`patterns/fan-out.md`, `cookbooks/function_calling.md`)**: Batch intent/tool-family routing (`Choice`), per-tool safety `Noul`s, and domain-specific risk `Noul`s in a single parallel `system_one` request (`~11.5x` lower cost, `~9.6x` lower latency).
    2. **Composite Scoring (`patterns/composite-scoring.md`)**: Evaluate independent `Score` (normalized as $\text{score}/(N-1)$) and hard-veto `Noul` dimensions in one request and combine in Python so weights and thresholds can be retuned without re-running inference.
