## ADDED Requirements

### Requirement: Workstation Coding Agents and Editors SHALL Expose Tiered Gemini 4 Carbon Combos Alongside Existing OmniRoute Models Without Altering Defaults
All configurable workstation coding agents and editor integrations SHALL register `gemini-4-carbon`, `gemini-4-carbon-high`, `gemini-4-carbon-medium`, and `gemini-4-carbon-low` (`1,000,000` / `1,048,576` context window; `262,144` max output tokens where supported, or `65,536` where client schemas cap `max_tokens`) under their existing active OmniRoute provider blocks while preserving every tool's startup default model and `x-omniroute-no-memory: "true"` header invariants.
