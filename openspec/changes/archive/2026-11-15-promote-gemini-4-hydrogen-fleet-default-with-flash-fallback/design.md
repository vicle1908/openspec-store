# Design

## Context

See `proposal.md` — Why for problem motivation. Following archived change `2026-11-13-add-omniroute-gemini-4-hydrogen-and-sync-fleet`, OmniRoute (`v3.8.53` on `127.0.0.1:20128` / `127.0.0.1:20129`) already exposes `gemini-4-hydrogen{,-xhigh,-high,-medium,-low}`, `16` capability overrides (`1,048,576` context, `262,144` max output tokens, `reasoning_efforts: "low,medium,high,xhigh"`), and `3` combo-scoped reasoning-routing rules (`low`, `medium`, `xhigh`, with `high`/omitted falling through to `gemini-4-hydrogen-high`).

Live read-only forensic inspection on `2026-11-14` surfaced five technical constraints that govern this cutover:
1. **Banned Connections in Both OmniRoute SQLite and OMP `agent.db`**:
   - In OmniRoute `provider_connections`, `38782750` (`vicgnome19096@gmail.com`) and `ea0d6c23` (`vicgnome19092@gmail.com`) are both `is_active = 0, test_status = 'banned'`. While `ea0d6c23` was already removed from `muse-spark-1.3` on `2026-11-11` (leaving 1 step `[combo-ref: gemini-3.8-flash-high]`, `targetTimeoutMs: 120000`), banned `38782750` still sits at step `[0]` in `gemini-4-hydrogen-{xhigh,high,medium,low}`, `gemini-3.8-flash-high`, `claude-opus-5.5`, and `claude-sonnet-5.5`. Meanwhile `0532bad4` and `338764b8` downgraded to `g1-pro-tier` (`gemini-4-hydrogen-disabled`), leaving **6 active Hydrogen accounts** (`5` WTU-Pro + `1` Ultra `62af823b`) and **10 active non-banned Pro accounts** (`7` Flash-only).
   - In OMP's native `~/.omp/agent/agent.db` (`auth_credentials`, `auth_credential_blocks = []`), **7 of the 13 `google-antigravity` rows are banned** (`id IN (5, 8, 9, 12, 13, 16, 19)`), 1 is inactive (`id = 15`), 4 active rows are Flash-only (`gemini-4-hydrogen-disabled`), and **only 1 row (`id = 3`, Ultra `vicgnome19094`) has Hydrogen** (the 5 WTU-Pro Hydrogen accounts live only in OmniRoute). Moving OMP `advisor` onto native `google-antigravity/gemini-4-hydrogen-*` would hammer the lone Ultra account!
2. **Quota Coupling & `/v1/models` `min()` Cap (`src/app/api/v1/models/catalog.ts:857`)**: `buildComboCatalogMetadata()` expands nested `combo-ref` targets and computes `minKnownNumber(maxOutputTokens)`: nesting `combo-ref: gemini-3.8-flash-high` (`maxOutputTokens: 65536`) directly inside `gemini-4-hydrogen*` would silently clamp `/v1/models` `max_output_tokens` on `gemini-4-hydrogen*` from `262144` down to `65536`. Conversely, `muse-spark-1.3` already advertises `65536` (`models.yml:360` / Muse `output_limit: 65536`), so `muse-spark-1.3` CAN safely nest `[combo-ref: gemini-4-hydrogen-high, combo-ref: gemini-3.8-flash-high]`.
3. **Single-Pass `applyReasoningRouting` (`src/sse/handlers/chat.ts:1031` & `open-sse/services/combo/runtimeUnits.ts:143`)**: `applyReasoningRouting()` runs once at top-level HTTP ingress before `handleComboChat`, and `executeComboRefUnit()` delegates to `runCombo` using the child combo's own `config` (`targetTimeoutMs: 180000`). Pointing `muse-spark-1.3` step `[0]` directly to `combo-ref: gemini-4-hydrogen-high` avoids an extra `combo-ref` hop while preserving child timeout semantics.
4. **Client Config, Port, and State-File Traps**:
   - **Claude Code Port & Zsh Arg Drift**: `~/.zshrc:334-335` currently exports `http://localhost:20128` and passes positional default `"gemini-3.8-flash-high"` to `_claude_with_profile`, while `claude-code-omniroute-pm-routing` mandates `http://127.0.0.1:20129`. Both `~/.zshrc:319,334,335` and `omniroute-pm.json` must converge on `http://127.0.0.1:20129` and `"gemini-4-hydrogen"` (`CLAUDE_CODE_EFFORT_LEVEL: "high"`).
   - **Hermes Dead Legacy Port `8045` & Root `moa.*` Block**: `~/.hermes/config.yaml` still carries a legacy `providers.antigravity` block pointing at dead port `127.0.0.1:8045` and root `moa.{reference_models,aggregator}` (`lines 539-547`) pointing at `gemini-3.8-flash-high`, while `moa.presets.fast` has no OmniRoute slot. `fallback_providers` must only reference `[{provider: omniroute, model: gemini-3.8-flash-high}]`.
   - **Codex, Pi, Goose, Droid, Grok, Kimi, OpenCode/Kilo TUI State**: Codex `cockpit-model-catalog.json` requires object-array `supported_reasoning_levels` (`[{"effort": ..., "description": ...}]`, `mode 0644`); Pi sets `defaultThinkingLevel: "high"` and routes `reviewer` (`xhigh`) directly to `omniroute-responses/gemini-4-hydrogen-xhigh` in `settings.json` so `models.json` stays untouched; Goose configures `providers.custom_omniroute.model` (no top-level `model:` key); Droid `droid exec` ignores `sessionDefaultSettings.model` unless `-m "custom:OmniRoute-gemini-4-hydrogen"` is passed; Grok `~/.grok/config.toml` has no `session_summary` key; Kimi rejects `"xhigh"`; OpenCode (`~/.local/state/opencode/model.json`) and Kilo (`~/.local/state/kilo/model.json` `model.code.modelID` only) cache active models on disk.
5. **Runtime Env Fallback & Bootstrap Script Scope**: `~/.shb/.env` still sets stale `SHB_FALLBACK_MODEL=Advance` alongside `SHB_DEFAULT_MODEL=gemini-3.8-flash-high` (both should converge to `gemini-4-hydrogen` / `gemini-3.8-flash-high`), whereas `scripts/setup-macbook-omniroute-client.sh` (359 lines, already byte-identical with `~/Developer/scripts/setup-macbook-omniroute-client.sh`) contains zero model-default templates (`--apply` only rewrites loopback URLs on client nodes and `--check` already validates all 19 combos), requiring read-only `--check` verification rather than code edits.

## Goals / Non-Goals

**Goals:**
- Promote `gemini-4-hydrogen` as the primary default across OMP OmniRoute/background roles and all 16 coding agents, CLIs, and IDEs (`pi`, `prime-agent`, `hermes`, `opencode`, `kilo`, `codex`, `kimi-code`, `grok`, `goose`, `droid`, `claude`, `muse`, `qwen`, `zed`, `cline`, `continue`) plus `~/.shb/.env`, with role-tiered thinking levels (`high` primary, `xhigh` explicit review/aggregator, `low` commit/summary/haiku/autocomplete).
- Retain `gemini-3.8-flash-high` (`google-antigravity/gemini-3.8-flash` on native OMP `advisor`) as the explicit fallback across all fallback-capable layers (`omp` `retry.fallbackChains`, `hermes` `fallback_providers`, `continue` `models[]`, `muse-spark-1.3` step `[1]`, `~/.shb/.env` `SHB_FALLBACK_MODEL`) and keep it selectable in every client catalog/picker.
- Prune banned `38782750` from all 7 affected live OmniRoute combos (`gemini-4-hydrogen-{xhigh,high,medium,low}`, `gemini-3.8-flash-high`, `claude-opus-5.5`, `claude-sonnet-5.5`) and prune the 7 banned OAuth rows from `~/.omp/agent/agent.db`.

**Non-Goals:**
- Nesting `combo-ref: gemini-3.8-flash-high` inside `gemini-4-hydrogen*` combos (preserves `max_output_tokens: 262144` in `/v1/models`).
- Modifying `~/.omp/agent/models.yml`, `~/.pi/agent/models.json`, git-tracked `~/Omniroute` source files, SHB Python repo code defaults, or remote files on `macbook-pro-m5` (`/Users/vinhlk/**`).

- **Choice**:
  1. Snapshot `/app/data/storage.sqlite` via `better-sqlite3` `.backup()` to `/Users/androidteam/.omniroute/snapshots/pre-hydrogen-default-<ts>.sqlite` (`mode 0600`, `PRAGMA quick_check = ok`, retaining `<= 5` snapshots).

     - Remove banned `38782750` from `gemini-3.8-flash-high` (`7555d851`), `claude-opus-5.5` (`4b2430da`), and `claude-sonnet-5.5` (`9447399c`), leaving the 10 active non-banned Pro connections (`9c033d6f`, `37f9924d`, `573e3f41`, `3f3085b1`, `a94216f4`, `a7580e21`, `f511d061`, `9ad0a196`, `9d66311f`, `ce95e1cb`).

## Risks / Trade-offs

- **[Risk] Concentrating default load onto 6 active Hydrogen `agy` accounts accelerates 5-hour quota depletion** → **Mitigation**: Prune banned `38782750` and `ea0d6c23`, route fast/background slots at `:low` (`gemini-4-hydrogen-low`), step Claude and Codex defaults from `xhigh` to `high`, keep OMP `advisor` off Ultra quota, and retain `gemini-3.8-flash-high` (`10` active accounts) across all fallback chains and pickers.
- **[Risk] `droid exec` or IDE extensions reset config permissions to `0644`** → **Mitigation**: Re-run `chmod 600` on `~/.factory/settings.json` and sensitive provider configs after probes and record `stat -L` + SHA-256 in `evidence.md`.
- **[Risk] Cline CLI absent from `PATH` and Continue autocomplete latency with thinking models** → **Mitigation**: Validate JSON schemas (`providers.json`, `config.json`), disable thinking on Continue `tabAutocompleteModel` (`completionOptions: {"reasoning": false}` per Continue official docs), and execute protocol-exact `/v1/chat/completions` smoke requests matching Cline (`gemini-4-hydrogen` with reasoning) and Continue (`gemini-4-hydrogen` + `gemini-4-hydrogen-low` autocomplete latency) during Phase 5.
