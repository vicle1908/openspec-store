# Proposal

## Why

The shared OmniRoute (`v3.8.53`) gateway on `iosteam-mac-mini` already exposes `gemini-4-hydrogen{,-xhigh,-high,-medium,-low}`, yet all workstation coding agents, CLIs, and IDEs (`omp` subagent/auxiliary roles, `pi`, `prime-agent`, `hermes`, `opencode`, `kilo`, `codex`, `kimi`, `grok`, `goose`, `droid`, `claude`, `muse`, `qwen`, `zed`, `cline`, `continue`, and `~/.shb/.env`) still default to `gemini-3.8-flash-high` (with `~/.shb/.env` still setting stale `SHB_FALLBACK_MODEL=Advance`), while live `gemini-4-hydrogen-*`, `gemini-3.8-flash-high`, `claude-opus-5.5`, and `claude-sonnet-5.5` combos retain banned step `[0]` (`38782750`) and `muse-spark-1.3` still points solely to `gemini-3.8-flash-high`.

Promoting `gemini-4-hydrogen` (with role-tiered thinking levels) as the fleet default across every coding agent, CLI, and IDE—while retaining `gemini-3.8-flash-high` (`google-antigravity/gemini-3.8-flash` on native OMP) as the explicit fallback—moves interactive and subagent traffic to Gemini 4 Hydrogen without losing access to the 7 Pro/Free `agy` accounts that only support Flash 3.8.
