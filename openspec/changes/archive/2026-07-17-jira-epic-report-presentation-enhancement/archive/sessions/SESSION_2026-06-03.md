## Technical Details

### Data Flow
```
Report Model (epics, child_tasks, project_bugs)
  ↓
Collect all items into unified dictionary
  ↓
Identify root blockers: v.blocks AND NOT v.blocked_by
Identify blocked items: v.blocked_by exists
  ↓
Sort root blockers by impact_radius DESC
Sort blocked items by blocker_chain_depth ASC
  ↓
Render in report format (Markdown, HTML, Spreadsheet)
```

### Key Algorithms

1. **Root Blocker Detection**
   ```python
   root_blockers = [
       (k, v) for k, v in all_items.items()
       if v.blocks and not v.blocked_by
   ]
   ```

2. **Cross-Sprint Impact**
   ```python
   blocked_in_this_sprint = sum(
       1 for k in items.values()
       if item.key in k.blocked_by and k.sprint_name == sname
   )
   blocked_in_other_sprints = impact_radius - blocked_in_this_sprint
   ```

3. **Blocked Percentage**
   ```python
   blocked_pct = round((blocked / total * 100)) if total > 0 else 0
   ```

### Performance Characteristics
- **All operations:** O(n) single-pass collection
- **Sorting:** O(n log n) for root blockers by impact
- **Memory:** O(n) unified item dictionary
- **Expected overhead:** <50ms for 200 items
