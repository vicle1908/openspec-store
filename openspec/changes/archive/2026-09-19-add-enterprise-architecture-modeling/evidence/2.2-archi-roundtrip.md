## Round-Trip Command (ACLI headless)

```
/Applications/Archi.app/Contents/MacOS/Archi \
  -application com.archimatetool.commandline.app -consoleLog -nosplash \
  --xmlexchange.import /Users/androidteam/Developer/openspec-store/docs/architecture/models/canonical.xml \
  --xmlexchange.export /tmp/archi-rt/canonical-archi-roundtrip.xml \
  --xmlexchange.exportFolders
```

Operational notes (see `docs/architecture/toolchain-verification.md` for the full form):
ACLI resolves `--xmlexchange.*` file arguments against its own working directory,
not the shell's, so absolute paths are required — a relative import path fails
with `Model was not loaded`. ACLI also exits 0 even when a provider fails, so
verify the output file exists and re-opens rather than trusting the exit code.

Output file preserved at `evidence/2.2-archi-roundtrip-canonical.xml`
(SHA-256 `3aa06c24c3af09e4a4c59fb00c9f4e4ad0dde00836af5e6d4e7c1a5e9e426b00`).
