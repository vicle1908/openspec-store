## Why

Multiple focused verifications established that Antigravity, Claude Code, and Codex can be orchestrated from Hermes, but their live providers and feature coverage differ. A final provider-aware consolidation is required so CLI capability, configured-provider behavior, and documentation-only claims are not conflated.

## What Changes

- Inventory installed CLI versions, authentication modes, configured provider/model identities, and relevant feature flags without recording credential values.
- Re-run bounded provider-backed probes for core automation, tool-enabled coding, machine-readable transport, structured output, session continuation, and configured MCP discovery where safely available.
- Classify each feature as verified, provider-limited, CLI-surface-only, or not tested.
- Correct Hermes skill language where live provider behavior differs from generic upstream capability.
- Consolidate prior archived evidence into one final matrix while preserving historical archives.

## Impact

- Hermes skills: `antigravity`, `claude-code`, and `codex` only if corrections are required.

## Non-Goals

- Exercising every interactive TUI command.
- Testing destructive permissions or dangerous bypass behavior.
- Enabling experimental feature flags.
- Treating one model/provider result as universal behavior for the CLI.
